# Bhavya Date Invitation 💗

The website is configured to email form submissions through FormSubmit.

## Activate the form
1. Upload the updated `script.js` to your GitHub repository, replacing the old file.
2. Open the live website and submit one test response.
3. Check the recipient inbox for a FormSubmit activation email and click its activation link. Check Spam/Promotions if needed.
4. Submit another test response and confirm the email arrives.

Important: the email address is embedded in the public JavaScript endpoint and will be visible in your public repository source. If you do not want this, use a configured form service endpoint/token instead.

## GitHub Pages
Keep `index.html`, `style.css`, and `script.js` in the repository root. Under Settings → Pages, select Deploy from a branch, `main`, and `/(root)`.
